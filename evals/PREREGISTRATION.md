# Pre-registration — Unbilled evaluation

Committed **before** any sweep output exists. The commit hash of this file is quoted in `evals/results.md`, the README, and the demo video. Nothing below changes after the sweep starts; bugs that crash or mis-score are fixed in commits that say so.

## World
- Sealed synthetic company generated by `python -m unbilled.world` with `WORLD_SEED=20260906`; 12 vendors (8 accrual-relevant, 4 negative cases); periods 2025-08 … 2026-08.
- Latent parameters live in `fixtures/world_truth.json`, which agent code never reads. Only `evals/grade.py` (post-hoc) and the simulated controller (standing in for the human reviewer) read it.

## Closes and arms
- Demo closes: 2026-04, 2026-05, 2026-06, 2026-07 (sequential; each close's memory is the previous close's committed ledger).
- Canary periods for the Validator: 2026-02, 2026-03 (closed; actuals known).
- Arms: `main` (memory on, validator on; seeds 1 and 2 → estimator temperature 0.2 / 0.7), `memory_off` (empty ledger every close; seed 1), `validator_off` (memory on, every proposed op committed; seed 1; run only if time allows).

## Metrics (in order of importance)
1. **Accrual MAPE** — mean of `|final_amount − actual| / actual` over vendors with `should_accrue = true` whose actual bill has arrived by a later close; pending actuals are excluded, never scored as zero. *Derived.*
2. **Completeness** — precision and recall of "accrue / don't accrue" over all vendors per close (negatives count). *Derived.*
3. **Reliability** — pass@1 and pass^2: a vendor passes a seed when the final amount is within materiality `max(10%, $500)` of the actual; pass^2 requires both seeds. *Derived.*
4. **Cost** — USD per close from provider `usage`; cache hit rate. *Measured.*
5. **Speed** — wall-clock seconds per close; controller touches (escalations + edits + rejects). *Measured.*
6. GL account accuracy vs the vendor's default account. *Authored label — reported separately and labelled as such.*

## Validator decision rule
Commit a candidate ledger iff, on canary replay at temperature 0: `MAPE_candidate ≤ MAPE_incumbent − 0.02` and `cost_candidate ≤ 1.10 × cost_incumbent` and recall does not drop by more than 0.10. Otherwise roll back and record the delta.

## What counts as "improved"
`main` MAPE at 2026-07 lower than at 2026-04 by at least 0.10 absolute, with `memory_off` not showing the same drop. Touches and $/close falling are supporting evidence, not the claim.

## Honesty
The sweep's reviewer is the simulated controller (world-truth with noise and accountant reason codes); the recorded demo's reviewer is a human. Rate-limit retries and total spend are reported.
